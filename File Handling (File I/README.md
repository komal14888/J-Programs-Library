## About
This repository contains frequently used C programs and basic algorithms.

## Programs

1. **Bubble Sort:** Sorts array elements in ascending order.
2. **Linear Search:** Searches for an element in an array.
3. **Factorial:** Calculates factorial using recursion.
4. **File I/O:** Demonstrates writing data into a file.
5. **Matrix Multiplication:** Multiplies two 2x2 matrices.

## How to Compile and Run

Compile using GCC:

```bash
gcc bubble_sort.c -o bubble_sort
```

Run:

```bash
./bubble_sort
```

Similarly, compile and run other programs by changing the filenames.
